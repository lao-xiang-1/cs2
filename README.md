# cs2辅助瞄准工具v2.1

## 项目介绍
项目分为两部分，一个是python版，在python文件夹下；外面的是使用c++推理的版本，速度更快而且封装好了不用配环境。

## 主要思路
1. 截图取屏幕中心640*640的图像
2. 基于yolov8 tensorrt处理图像，获取敌人位置
3. 根据识别结果移动准心

---

## 使用方法
1. 先安装罗技鼠标驱动(也放在release的压缩包里了)，注意这个貌似只能安装在c盘，最好不要更改安装路径。
每次使用时都需要先打开罗技驱动（开启后直接退出就好，到电脑关机为止都有效）
2. 双击运行cs2_det.exe
3. 配置信息在config文件夹下enemy_config.json中，
其中三个数字作用：
第一个数字： 0表示打头，1表示打身体
第二个数字： 0表示打CT方，1表示打T方
第三个数字： 1表示开启自动开火，0表示不开
(每次切换都需要重启程序)
